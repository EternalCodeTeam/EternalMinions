# EternalMinions

EternalMinions is a Paper plugin for efficient, persistent minion automation.

## Modules

- `eternalminions-api` — stable contracts and immutable integration models.
- `eternalminions-plugin` — runtime implementation and the Paper plugin.
- `eternalminions-api-examples` — executable examples that depend only on the public API.

Developer documentation is available in [docs/API.md](docs/API.md). The complete coverage roadmap
is tracked in [docs/API-CHECKLIST.md](docs/API-CHECKLIST.md).
